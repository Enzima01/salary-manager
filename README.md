# 💰 Gerenciador de Salário
---

## 🇧🇷
Sistema desktop desenvolvido em Java para auxiliar no gerenciamento e planejamento do salário mensal.

O usuário pode cadastrar categorias de gastos, definir porcentagens, criar gastos fixos e acompanhar automaticamente quanto do salário está comprometido e quanto ainda resta disponível.

### ✨ Funcionalidades

* Cadastro de categorias
* Categorias por porcentagem
* Categorias por valor de gasto
* Gastos fixos
* Edição de categorias
* Exclusão de categorias
* Cálculo automático dos valores
* Exibição do total utilizado
* Exibição do valor restante
* Exibição dos percentuais utilizados e restantes
* Salvamento de templates em SQLite
* Carregamento de templates salvos
* Geração de relatório TXT
* Alternância entre tema claro e escuro

### 🛠 Tecnologias Utilizadas

* Java
* Java Swing
* SQLite
* JDBC
* FlatLaf

### 📋 Como Funciona

#### Categoria por Porcentagem

Exemplo:

```text
Salário: $ 3.000

Alimentação: 20%
Lazer: 10%
Investimentos: 15%
```

O sistema calcula automaticamente os valores com base no salário informado.

#### Categoria por Gasto

Exemplo:

```text
Internet: $ 120
Academia: $ 90
Streaming: $ 50
```

Os valores podem ser digitados manualmente.

#### Gasto Fixo

Ao marcar a opção **Gasto Fixo**, o valor informado fica bloqueado na tela principal, impedindo alterações acidentais.

### 📄 Relatório

O sistema pode gerar um relatório contendo:

* Salário informado
* Categorias cadastradas
* Valores calculados
* Total gasto
* Valor restante
* Data e hora da geração

# 💰 Salary Manager
--

## 🇺🇸
Desktop application developed with Java to help users manage and plan their monthly salary.

Users can create expense categories, define percentages, create fixed expenses, and automatically track how much of their salary has been allocated and how much remains available.

---

### ✨ Features

* Category creation
* Percentage-based categories
* Expense value categories
* Fixed expenses
* Category editing
* Category deletion
* Automatic calculations
* Total expense display
* Remaining salary display
* Used and remaining percentage indicators
* Save templates using SQLite
* Load saved templates
* TXT report generation
* Light and dark theme support

### 🛠 Technologies Used

* Java
* Java Swing
* SQLite
* JDBC
* FlatLaf

### 📋 How It Works

#### Percentage Category

Example:

```text
Salary: $3,000

Food: 20%
Entertainment: 10%
Investments: 15%
```

The application automatically calculates the values based on the entered salary.

#### Expense Category

Example:

```text
Internet: $120
Gym: $90
Streaming: $50
```

Values can be entered manually.

#### Fixed Expense

When the **Fixed Expense** option is enabled, the entered amount becomes locked on the main screen, preventing accidental modifications.

### 📄 Report

The application can generate a report containing:

* Entered salary
* Registered categories
* Calculated values
* Total expenses
* Remaining balance
* Date and time of generation
